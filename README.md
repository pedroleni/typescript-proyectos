# typescript-proyectos-avanzados

Proyectos avanzados de Tech Study Tracker para esta tecnología. Cada
carpeta es un proyecto independiente, con su propio `package.json` —
**entra en la carpeta (`cd <carpeta>`) antes de instalar dependencias**
o ejecutar nada.

## Proyectos

- [`buscador-personajes`](./buscador-personajes) — Buscador de personajes — uniones discriminadas y comprobación de exhaustividad
- [`bus-eventos`](./bus-eventos) — Bus de eventos tipado (publish/subscribe)
- [`cliente-zod`](./cliente-zod) — Cliente HTTP tipado y validado con Zod
- [`maquina-estados`](./maquina-estados) — Máquina de estados finita, genérica y tipada

La rama `main` de este repo tiene el punto de partida de cada proyecto
(con TODOs); la rama `solucion` tiene la implementación completa de
todos ellos, por si te atascas en alguno.
